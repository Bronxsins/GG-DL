## GAME GRIDS DOWNLOADER
*GG:DL (Game Grids Downloader) is an all-in-one desktop app for browsing and downloading game artwork as well as managing metadata in RetroBat.* 🎮

## *WHAT IT DOES*
* **Live Search:** Search for any game with live, as-you-type suggestions. 🔍
* **Artwork & Screenshots:** Browse and download official artwork by category: Grids (box art), Heroes (banners), Logos, and Icons, all sourced from SteamGridDB and Screenshots via RAWG.io. 🖼️
* **Filtering & Sizing:** Filter results by file type (PNG, JPEG, GIF, WEBM, ICO, or SVG) and adjust thumbnail preview size. ⚙️
* **Flexible Actions:** Select multiple items and batch download them, or right-click any item for a full-size preview, or double-click to instantly download just that one. 📥
* **History & Naming:** Every download is named consistently, for example *Halo Infinite Box Art.png*, and logged in a Downloaded history tab, where you can reopen its folder or remove it from the list. 📂
* **Performance:** Loads results in batches with infinite scroll, so large result sets stay fast and responsive. ⚡

## *EXTRAS*
* **Theming:** Dark or Light mode, plus a fully customizable accent color that applies across the whole UI. 🎨
* **API Management:** Built-in API key management with live validation, so you know immediately if a key doesn't work. 🔑
* **In-App Guide:** An in-app "How To Use" guide with clickable links to get your free API keys. 📖
* **Architecture:** Runs as a single portable Python file using PySide6 and Nuitka 🚀
