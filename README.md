# GG:DL (Game Grids Downloader)

GG:DL is an all-in-one desktop app for browsing and downloading game artwork as well as managing metadata in RetroBat.

## What It Does
* Search for any game with live, as-you-type suggestions.
* Browse and download official artwork by category: Grids (box art), Heroes (banners), Logos, and Icons sourced from SteamGridDB.
* Filter results by file type (`PNG`, `JPEG`, `GIF`, `WEBM`, `ICO`, or `SVG`) and adjust thumbnail preview sizes.
* Select multiple items and batch download them, right-click for a full-size preview, or double-click to instantly download a single asset.
* Every download is named consistently (e.g., *Halo Infinite Box Art.png*) and logged in a **Downloaded History** tab to reopen folders or remove entries.
* Loads results in batches with infinite scroll to keep large sets fast and responsive.

## Extras and Customization
* Dark or Light mode, plus a fully customizable accent color across the entire UI.
* Built-in API key management with live validation.
* An in-app "How To Use" guide with clickable links to get your free API keys.
