# Game Grids Downloader
> ***GG:DL (Game Grids Downloader) is a desktop app for browsing and downloading game artwork without needing to visit the SteamGridDB or RAWG websites directly.***
> 
> **What it does:**
> *▸ Search for any game with live, as you type suggestions
> ▸ Browse and download official artwork by category: Grids (box art), Heroes (banners), Logos, and Icons, all sourced from SteamGridDB
> ▸ A dedicated Wallpaper tab pulls official game screenshots via RAWG.io, matched intelligently to the exact game you select
> ▸ Filter results by file type (PNG, JPEG, GIF, WEBM, ICO, or SVG) and adjust thumbnail preview size
> ▸ Select multiple items and batch download them, or right click any item for a full size preview, or double click to instantly download just that one
> ▸ Every download is named consistently, for example Halo Infinite Box Art.png, and logged in a Downloaded history tab, where you can reopen its folder or remove it from the list
> ▸ Loads results in batches with infinite scroll, so large result sets stay fast and responsive*
> 
> **Also capable of:**
> *▸ Dark or Light mode, plus a fully customizable accent color that applies across the whole UI
> ▸ Built in API key management with live validation, so you know immediately if a key doesn't work
> ▸ An in app "How To Use" guide with clickable links to get your free API keys
> ▸ Runs as a single portable Python file using PySide6, with a splash screen, custom taskbar and window icon, and no external asset files required*
> 
> __At its core: point it at a game, and it hands you clean, organized, ready to use art assets for it.__
