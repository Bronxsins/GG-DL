# Game Grids Downloader
<div class="app-description">
    <p class="lead"><strong>GG:DL (Game Grids Downloader)</strong> is an all-in-one desktop app for browsing and downloading game artwork as well as managing metadata in RetroBat.</p>

    <h3>What It Does</h3>
    <ul class="feature-list">
        <li>Search for any game with live, as-you-type suggestions.</li>
        <li>Browse and download official artwork by category: Grids (box art), Heroes (banners), Logos, and Icons sourced from SteamGridDB, plus screenshots via RAWG.io.</li>
        <li>Filter results by file type (PNG, JPEG, GIF, WEBM, ICO, or SVG) and adjust thumbnail preview sizes.</li>
        <li>Select multiple items and batch download them, right-click for a full-size preview, or double-click to instantly download a single asset.</li>
        <li>Every download is named consistently (e.g., <em>Halo Infinite Box Art.png</em>) and logged in a Downloaded history tab to reopen folders or remove entries.</li>
        <li>Loads results in batches with infinite scroll to keep large sets fast and responsive.</li>
    </ul>

    <h3>Extras and Customization</h3>
    <ul class="feature-list">
        <li>Dark or Light mode, plus a fully customizable accent color across the entire UI.</li>
        <li>Built-in API key management with live validation.</li>
        <li>An in-app "How To Use" guide with clickable links to get your free API keys.</li>
    </ul>
</div>
